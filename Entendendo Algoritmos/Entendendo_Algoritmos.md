# Entendendo Algoritmos
## Anotações e Códigos de Estudo

Este repositório contém minhas anotações e implementações dos algoritmos apresentados no livro "Entendendo Algoritmos: Um guia ilustrado para programadores e outros curiosos" de **Aditya Y. Bhargava**.

O objetivo é documentar meu processo de aprendizado, com exemplos práticos em Python para fixar os conceitos.

## Conteúdo

### Capítulo 1 - Introdução a Algoritmos
* Pesquisa Binária
* Anotação Big O

### Capítulo  2 - Ordenação por seleção (*selection sort*)
* Arrays
* Listas Linkadas (*linked list*)
